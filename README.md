# 民主不是你想的那樣

**V0.1（教育原型）**

一個「反直覺」的臺灣民主與憲政題庫。每一題都有一個聽起來很合理的情境和幾個選項，你先憑直覺選，答完才看到：**憲政體制的答案 → 依據（條文原文＋官方連結）→ 解釋 → 為什麼直覺會出問題**。有些題本身沒有標準答案（例如全民投票與憲法解釋、死刑與民意、選舉期間的深偽影片），答案頁會列出現行規則、各方最有力的論點，以及每個選項沒說出口的前提，不替你下結論。

👉 **線上版：<https://aphasialiu.github.io/civicinquiry.undone/>**（點開就能玩，不用登入、不用安裝）

## 它不做什麼

- **不收集任何人的作答。** 你的答案只留在你自己的瀏覽器分頁裡，關掉就消失；除非你自己選擇存在這台裝置上。
- 沒有帳號、沒有追蹤碼、沒有廣告、沒有外部字型或圖片。
- 目前**尚未經過獨立的法律與教育專業審查**，不構成法律意見。法條原文取自全國法規資料庫，已逐字核對；解釋與論點是作者整理的，歡迎指正。

## 怎麼玩、怎麼分享

| 方式 | 適合 | 做法 |
|---|---|---|

## 怎麼確認它沒有偷做什麼

對 HTML 檔案放心是合理的要求。你可以這樣確認，由簡單到嚴謹：

1. **關掉網路再開。** 把電腦的網路關掉（或開飛航模式），再開單一檔案版。如果一切照常，就表示它沒有靠網路在做事。
2. **看它宣告了什麼限制。** 檔案開頭有一行安全政策（Content-Security-Policy），寫明：不允許連到任何外部網址（`connect-src 'none'`）、只允許執行檔案裡那一段指定的程式、不允許送出表單。瀏覽器會強制執行。
3. **核對指紋。** 每個 Release 都附上檔案的 SHA-256。下載後在終端機執行 `sha256sum 檔名.html`（Windows 用 `certutil -hashfile 檔名.html SHA256`），結果和 Release 頁面寫的一樣，就是原版，沒被改過。
4. **自己從原始碼建置。** 全部程式都在這個倉庫，不需要信任我們：

   ```bash
   git clone https://github.com/aphasialiu/civicinquiry.undone.git
   cd civicinquiry.undone
   npm ci
   npm test           # 單元測試
   npm run build      # 產生 dist-single/ 裡的單一檔案
   ```

   需要 Node.js 20 以上。端對端測試（`npm run test:e2e`）會用本機的 Google Chrome 測建置後的版本，包含「沒有任何對外網路請求」的檢查。

**請只從這個倉庫的 Release 或上面的線上版取得檔案。** 轉傳過幾手的檔案，請先核對指紋。

## 給開發者

- 內部設計、需求對照與已知限制：[docs/DEVELOPMENT.md](docs/DEVELOPMENT.md)
- 部署與維護手冊：[docs/DEPLOYMENT.md](docs/DEPLOYMENT.md)
- 題庫原稿：`content-src/constitution.quiz.json`；官方條文素材庫：`src/data/corpus.json`（`node scripts/build-corpus.mjs` 重抓）。
- 網站每週自動重新發布一次，並把題庫的有效期限設為 60 天（純靜態網站沒有撤回服務，撤回題目就是改檔再推上去）。如果排程停了、超過 60 天沒人更新，題目會被降為「歷史閱讀」，這是設計，不是壞掉。見 `.github/workflows/pages.yml`。
- 想改題目：先看 `tests/corpus.test.ts`，所有引用的條文與判決主文都必須逐字出自官方文字，測試會擋。
