# 部署與維護手冊

這份文件給「要把網站放上線的人」。每一步都寫了前提；看不懂請先問，不要跳步。

## 一、先選模式

| 模式 | 你得到什麼 | 你需要什麼 |
|---|---|---|
| **靜態模式**（最簡單） | 測驗、解釋、預審來源清單、離線閱讀（選配） | 任何能放靜態檔案的主機（對象儲存、靜態網站託管） |
| **靜態＋搜尋代理** | 上面全部，加上「搜尋最新資料」 | 再加一台能跑 Node.js 的地方，以及搜尋供應商的合約 |

**目前搜尋代理只有「測試替身」**，結果是假資料。在你取得供應商的書面使用條款（能不能顯示、能不能快取）並做完 30 組真實查詢試查之前，請用靜態模式，或把搜尋面板標示清楚。

## 一之二、讓大家「點連結就能用」

- **網站連結**：把 `dist-static/`（或 `dist/`）放到任何靜態網站空間，大家就用同一個網址。出題的人用作者工具產生「分享連結」，內容在網址的 # 後面，不會經過你的主機。
- **單一檔案**：`npm run build` 之後，`dist-single/civic-inquiry-constitution.html` 就是內建 12 題的單一檔案，直接傳給別人即可。作者工具的「下載成單一檔案」需要網站上有 `single-template.html`（`npm run build` 會自動放進 `dist/`；`build:static`、`build:pwa` 不會）。
- **不收結果**：這個版本不會把任何人的作答傳回給出題的人，這是刻意的設計（沒有伺服器、沒有個資）。

## 二、靜態模式（一步一步）

前提：電腦裝了 Node.js 20 以上。

```bash
npm ci
npm run build:static
```

產物在 `dist-static/`，整個資料夾上傳到主機即可。要離線閱讀（PWA）請改用：

```bash
npm run build:pwa
```

產物在 `dist-pwa/`。

主機必須設定的回應標頭（`public/_headers` 是 Netlify／Cloudflare Pages 格式的範例；其他主機請照著設）：

- `Content-Security-Policy`：照 `public/_headers` 的內容，**不要**加 `unsafe-eval`、`unsafe-inline`
- `Referrer-Policy: no-referrer`
- `X-Content-Type-Options: nosniff`
- `/content/status.json` 要 `Cache-Control: no-store`

隱私檢查：主機要關掉請求本文與查詢字串的記錄；若主機強制記錄 IP，請公開保留期限。做不到就不能宣稱通過隱私驗收。

## 三、狀態目錄會在 24 小時後過期（很重要）

`status.json` 是「這些題目現在還有效嗎」的依據，最長只有 24 小時有效。過期後所有題目都會自動變成「歷史閱讀」、不計分。這是設計，不是壞掉。

所以你必須**每天（建議每 12 小時）重新發布一次**：

```bash
npm run content
```

然後把 `public/content/status.json` 上傳覆蓋。可以用排程工具（例如 GitHub Actions 的 schedule、主機的 cron）自動做。**如果沒有排程，網站隔天就全部變成歷史閱讀。**

## 四、撤回一題（發現答案錯了）

目標：15 分鐘內讓線上生效。

```bash
npm run withdraw -- 題目代號@版本 "撤回理由（讀者會看到）" [新版本]
npm run content
```

再把 `public/content/status.json` 上傳。讀者重新整理後會看到「這一題已撤回」和你寫的理由。

重大錯誤的處理時限（規格）：通知內容負責人後 1 個工作日內初判，若有可信的錯誤證據，立刻撤回；完整更正目標 5 個工作日，或公告延遲的理由。

離線的人無法即時收到撤回，這是固有限制（他們只能「歷史閱讀」，不會被當成現行題計分）。

## 五、回滾

靜態檔案是整包切換的：**保留上一版的資料夾**，出問題時把主機指回上一版即可。撤回狀態不要被回滾蓋掉：回滾後請重新執行第四節的撤回，或確認 `content-src/status-overrides.json` 沒有被舊版覆蓋。

## 六、搜尋代理（選配）

```bash
npm ci
npm run api            # 測試替身，預設在 http://localhost:8787
```

- 網站與代理必須在**同一個網域**（把 `/api` 轉給代理），瀏覽器才不需要跨網域。
- 環境變數見 `.env.example`。供應商金鑰只放在代理的環境變數。
- 配額是單一程序內的計數器。若你把代理部署成多個實例，必須改用共享的原子計數器，否則無法全站封頂。
- 預算：建議每月上限先設成你願意付的費用；到 80% 要有人被通知（**這個通知通道目前沒有做**，需要你接上電子郵件或訊息服務），100% 自動停用外部搜尋，畫面會退回預審清單，不影響測驗。
- 憑證外洩：先停代理、輪替金鑰、檢查費用；靜態網站可以照常運作。
- `Dockerfile` 是範例，**沒有實際建置驗證過**。

## 七、供應商停用

直接停掉代理即可：前端會顯示「搜尋沒有成功」並退回預審清單，測驗不受影響。若是靜態模式，請用 `build:static` 重新建置，不要留一個永遠失敗的按鈕。

## 八、備份與還原

- 讀者答案**不備份**（預設只在讀者的分頁記憶體）。
- 要備份的是 `content-src/`（題庫原稿、`status-overrides.json`）。建議放在版本控制，並每天備份。
- 還原演練：用備份的 `content-src/` 執行 `npm run build`，比對 `status.json` 的撤回項目是否都在。**這個演練還沒有人做過**，請在正式上線前做一次並記錄。
